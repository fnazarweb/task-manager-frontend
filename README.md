# Task Manager — Frontend

React frontend for a full-stack Todo List application, connected to a custom Node.js/Express REST API.

> Backend repository: [task-manager-backend](https://github.com/fnazarweb/task-manager-backend)
> 
> Live app: [todo-frontend-k1o4.onrender.com](https://todo-frontend-k1o4.onrender.com/)

## About

A Todo List app with user authentication — register, login, and manage your own tasks (create, edit, delete, filter by status). Built to practice React fundamentals together with real API integration, rather than mock data.

## Tech stack

- **React** (JSX, no TypeScript) — **React Router DOM v6** for navigation
- **Redux Toolkit + RTK Query** — Todo CRUD operations and caching
- **React Query** — included alongside RTK Query as practice with an alternative approach to server-state management
- **useContext** — application-level authentication state
- **Axios** — authentication requests (register, login, logout, current user)
- **CSS Modules + classnames** — isolated component styling
- **Docker** — containerized and deployed as a separate service on Render
